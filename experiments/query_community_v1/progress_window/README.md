# 实验进度窗口

双击 `ExperimentProgress.exe` 或 `LaunchProgress.vbs` 即可打开；重复打开不会创建多个相同窗口。关闭窗口只退出进度显示。程序使用Windows自带的.NET和WPF，不安装额外依赖。

默认读取 `D:/motif-phase4-work/route-a-rerank-20261109` 的启动记录及当前运行状态。总体进度按各图验证与测试查询量加权估算，不能把已完成组数直接当作耗时百分比；当前“证据提取”等阶段的百分比来自实验实际计数。

每2秒刷新文件，每15秒异步核对WSL主进程及其启动时间/命令。连续两次确认主进程消失，或实验主动报告失败时，窗口变红并发出桌面通知及提示音。进程还在但15分钟没有状态更新时显示黄色停滞提示，不误报为退出。WSL连接异常只显示“正在确认”，不据此判定实验中断。

窗口不自动重启实验，不停止实验，不修改已冻结的实验程序或结果。监视器自己的状态、错误日志只写入输出目录下的 `monitor/`。
