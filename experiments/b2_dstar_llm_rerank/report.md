## 文本与提示词

Freebase 与 WordNet 的公开词面/释义映射已下载并记录来源与哈希。多数目标图谱实体文本覆盖率为 99.8%–100%，WKIngram 为 0%，使用观察图 Top-5 有向邻接关系频次签名。逐图覆盖率见冻结清单。

路径中的中间实体也通过共享词典提供名称或类型签名；整数只是引用。输入使用完整 JSON，对超预算内容依次削减第三条路径、第二条路径及模体附加信息，保留全部候选与最强路径。若必需信息仍超预算则显式回退，不截断文本。

服务端 tokenizer 与 cl100k_base 不同。先预留 20% 余量，再核验 API 返回的实际 prompt_tokens；不把本地估算宣称为服务端精确计数。

## 运行与限制

- 四组 LLM 方法共用同一观察图合法 Top-30、5+3 决胜池和无证据门控，保证消融可比。因此“仅 LLM”仍共享结构选池规则，但其提示词不含路径或模体。
- 检索使用最多 512 个路径前缀的有界搜索，最多三跳；发生裁剪时显式标记。`no_evidence` 只表示未检索到证据，不代表图上必然断连。
- 正式进程使用逐批分数文件、逐公开查询缓存和持久化请求日志。模糊超时不自动重发，以免重复计费。
- `status.json` 记录进度、耗时、预计剩余时间、Token 和费用估算；`logs/full.log` 包含 tqdm 进度条。`scripts/ProgressWindow.ps1` 提供独立图形进度条。
- 当前固定参数不使用测试标签选择；可选高分差门控关闭。验证集按共享正向或逆向公开查询的连通组件划分选择/确认集。

## 时间与费用估算

验证与测试、三种子、四组 LLM 消融，在门控前最多 437,580 次调用。以本次小样本的稳定延迟与含超时延迟分别粗推，约 2.5–22 天，不能视为承诺；大图检索、门控命中率和 API 波动都会改变耗时。

按冒烟平均 Token 用量、所有调用都触发且输入缓存未命中的保守情景，费用约 208 美元。采用 2026-11-16 核查的 [DeepSeek 官方峰值价](https://api-docs.deepseek.com/quick_start/pricing/)；不是账单或绝对费用上限。详细假设见 `results/resource_estimate.json`。
